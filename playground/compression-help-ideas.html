Choosing an algorithm

Compression runs per-object. Filters skip already-compressed MIME types (images, archives, PDFs) and blobs under 1 KiB — these show up in arca_compression_skipped_total.

Help

Compression algorithms

Seven algorithms, chosen per-bucket. Each is tuned to a different trade-off curve between compression ratio and encode/decode CPU cost.

Changing the algorithm applies to future uploads only. Existing objects keep their current form until rewritten; run arca compress-existing --algorithm <name> to migrate them offline.
